# NutriAI API

FastAPI-сервер для анализа фото еды.

## Запуск (Windows PowerShell)

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
$env:GEMINI_API_KEY="ТВОЙ_API_КЛЮЧ"
$env:GEMINI_MODEL="gemini-3.8-flash"
$env:API_ACCESS_TOKEN="ВСТАВЬ_ДЛИННЫЙ_СЛУЧАЙНЫЙ_ТОКЕН"
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

## Эндпоинты

- `GET /health` — проверка состояния сервера и наличия ключа.
- `POST /analyze-food` — multipart-загрузка файла в поле `image`; возвращает JSON с предполагаемым блюдом, ингредиентами, массой, КБЖУ и диапазоном калорийности.

Если задан API_ACCESS_TOKEN, приложение должно отправлять такой же токен в настройках подключения. /health остаётся публичным для проверки состояния. Для сервера, доступного по сети, обязательно задай длинный случайный API_ACCESS_TOKEN и используй HTTPS; без токена API не защищён. Не помещай ключ Gemini в исходный код или Android APK. Бесплатный тариф имеет лимиты и условия, которые могут изменяться.

## Дополнительные эндпоинты (этап 3)

- `GET /products?q=курица&limit=20` — поиск по встроенному стартовому каталогу продуктов. Пищевая ценность указана ориентировочно на 100 г; это не замена этикетке конкретного продукта.
- `POST /recipes/suggest` — генерация до трёх рецептов по выбранным продуктам.
- `POST /menu/week` — генерация меню на семь дней и списка дополнительных покупок.

Пример JSON для `/recipes/suggest` и `/menu/week`:

```json
{
  "products": ["курица", "рис", "помидоры"],
  "calories_target": 2000,
  "preferences": "Недорого, просто, без острых блюд",
  "servings": 1
}
```

Если `API_ACCESS_TOKEN` задан, все маршруты кроме `/health` требуют заголовок `x-client-token`. Каталог `/products` работает без ключа Gemini, но также защищается токеном сервера, если он настроен. Генерация рецептов и меню использует тот же ключ Gemini, что и анализ фотографий, и зависит от доступности модели и лимитов бесплатного тарифа.


## Автотесты

Из папки `backend` установи зависимости `pip install -r requirements-dev.txt` и запусти `pytest -q`. Тесты используют заглушки вместо реальных запросов к Gemini и не требуют API-ключа.
