# NutriAI Stage 8 — исправления после аудита

- Ограничена загрузка изображения чтением порциями; добавлена проверка сигнатуры JPEG/PNG/WebP.
- Итоги анализа фото пересчитываются из ингредиентов, а не безусловно доверяют итоговым числам модели.
- Добавлена опциональная защита API заголовком `x-client-token` через `API_ACCESS_TOKEN`; обновлены настройки Android для ввода токена.
- Минимальная целевая калорийность для генерации меню повышена до 1200 ккал; поле цели можно оставить пустым.
- Для профиля младше 18 лет автоматическая цель калорий и индикатор прогресса отключены; генерация меню без фиксированной цели остаётся доступной.
- Восстановление резервной копии теперь прекращается при повреждённой записи вместо молчаливого пропуска.
- Добавлена явная зависимость `lifecycle-runtime-compose`.
- Добавлены тесты сервера для подписи изображения, токена API, нижнего ограничения калорийности и сверки итогов анализа.

Ограничения: Android-сборка в этой среде не выполнялась, поэтому Kotlin/Gradle ещё требуют подтверждения CI-сборкой. Каталог продуктов всё ещё стартовый, а значения КБЖУ приблизительные.
